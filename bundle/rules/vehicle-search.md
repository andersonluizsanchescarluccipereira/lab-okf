# Política ilustrativa

1. Identificadores estáveis exigem correspondência exata.
2. Marca e modelo podem usar busca lexical com filtros de categoria.
3. Erros de digitação podem usar fuzzy como fallback, com custo e relevância medidos.
4. Busca semântica é uma abordagem complementar, não obrigatória para este bundle OKF.

O catálogo está descrito em [veículos](/tables/vehicles.md).
