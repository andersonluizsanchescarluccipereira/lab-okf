# Regra de negócio (fictícia)

Um veículo é classificado como **SUV híbrido** quando:

1. O campo `categoria` é `SUV`.
2. O campo `motorizacao` é `híbrida`.

Na base de demonstração, o **GWM Haval H6** satisfaz essas duas condições.

# Origem do dado

Consulte a [tabela de veículos](/tables/vehicles.md) para verificar os campos e o registro.
O significado dos termos está no [glossário de SUV](/glossary/suv.md) e em
[motorização híbrida](/glossary/hybrid.md).

# Limites

Este documento ensina navegação por conhecimento. Não substitui homologação de
veículos nem dados oficiais de fabricantes.
