# Definição

Preço médio = soma dos preços / quantidade de veículos com preço informado.

Nos valores artificiais da [tabela de preços](/tables/prices.md):
(100000 + 80000 + 90000) / 3 = 90000 BRL.

# Limites

Não representa preço de mercado. Para média real, seria preciso definir amostra,
período, outliers e critérios de exclusão.
